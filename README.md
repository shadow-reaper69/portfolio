## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript
- **Bundler & Tooling:** Vite 8
- **Styling:** Tailwind CSS 4 + Custom Design Tokens (Light Editorial Palette)
- **Icons:** Lucide React
- **Linter:** Oxlint
- **Hosting & Deployment:** Vercel

---

## 🎨 Design Tokens & Palette

The portfolio strictly adheres to a refined light editorial aesthetic with high contrast and readable typography:

```css
--bg: #F3F4F5;          /* Page background */
--surface: #FFFFFF;     /* Card background */
--ink: #0F1419;         /* Primary text */
--muted: #46505B;       /* Secondary text */
--line: #D5DADF;        /* Border line */
--accent: #1D4ED8;      /* Primary accent blue */
--accent-hover: #123499;

/* Dark Footer */
--dark: #0F1419;
--on-dark: #E8ECEF;
--on-dark-muted: #A9B3BD;
--dark-line: #36404A;
--link-on-dark: #9DB8FF;
```

Typography:
- **Display & Headings:** `Montserrat`
- **Body & UI Elements:** `Poppins`

## 🚀 Getting Started

### 1. Installation

```bash
npm install
```

### 2. Development Server

```bash
npm run dev
```

Starts the local development server at `http://localhost:3000`.

### 3. Production Build

```bash
npm run build
```

Runs TypeScript typechecking (`tsc -b`) and bundles the static assets with Vite to `dist/`.

### 4. Code Quality & Linting

```bash
npm run lint
```

Runs Oxlint across the project.

---

## 🌐 Deployment

The project is configured for continuous deployment on [Vercel](https://vercel.com). Any commit pushed to the `main` branch triggers an automated build and deployment.
